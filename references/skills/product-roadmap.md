# Skill: Продуктовый роадмап

**Роль:** Product Owner
**Назначение:** построение продуктового роадмапа в формате Now/Next/Later или по темам.
**Имя файла:** `*_roadmap.md`

## 1. Формат Now / Next / Later

```
Now  (текущий квартал)   — в работе или скоро в работе, детально проработано.
Next (следующий квартал) — приоритизировано, требует уточнения деталей.
Later (горизонт 6–12 мес)— направление ясно, детали не проработаны.
```

## 2. Формат по темам (Theme-based roadmap)

Группировка не по фичам, а по бизнес-темам/целям:

```markdown
## Тема: Снижение оттока клиентов
- [Now]  Проактивные уведомления о рисках блокировки карты
- [Next] Программа лояльности для активных пользователей
- [Later] Персонализированные предложения на основе ML-модели
```

## 3. Обязательные элементы для каждого пункта роадмапа

1. Название инициативы (`US-*` или эпик `EPI-*`).
2. Связанная бизнес-цель / OKR (`GOAL-*`).
3. Горизонт (Now / Next / Later или квартал).
4. Ответственный (Product Owner / команда).
5. Ключевая метрика успеха.

## 4. Правила построения

- Roadmap — это про **направление и цели**, не про детальный список задач (это backlog).
- **Не указывай точные даты для Later** — только ориентировочный горизонт.
- Каждая тема должна быть привязана к измеримой цели (OKR / North Star Metric).
- Обновляй роадмап не реже раза в квартал.

## 5. Шаблон вывода

```markdown
# Roadmap: {продукт}

**Связанные бизнес-цели:** GOAL-001, GOAL-003

## Now (Q_ 20__)
| Инициатива | Цель | Метрика успеха |
|---|---|---|
| US-014 Быстрая оплата | GOAL-001 рост конверсии | conversion +5% |

## Next (Q_ 20__)
| Инициатива | Цель | Метрика успеха |
|---|---|---|

## Later (горизонт 6–12 мес)
| Направление | Гипотеза ценности |
|---|---|
| Персонализация ML | рост retention на 10% (требует подтверждения) |
```

## 6. Чек-лист качества

- [ ] Каждая инициатива привязана к бизнес-цели (`GOAL-*`).
- [ ] Указана метрика успеха для Now и Next.
- [ ] Later не содержит точных сроков и оценок трудоёмкости.
- [ ] Roadmap не превращён в backlog (нет мелких технических задач).
- [ ] При наличии тем — каждая тема привязана к измеримой цели (OKR / North Star).
- [ ] Привязки к User Stories (`US-*`) проставлены.
